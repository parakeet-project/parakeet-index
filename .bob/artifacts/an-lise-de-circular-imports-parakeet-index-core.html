2. Dependência de ordem frágil (não é ciclo, mas é risco)

ATENÇÃO   core/loaders/directory.py importa do próprio pacote pai

directory.py faz from parakeet_index.core.loaders import BaseFileLoader, BaseLoader, que aponta para o __init__ do mesmo pacote que está importando directory.py. Funciona hoje porque o __init__ importa base antes de directory, então BaseLoader e BaseFileLoader já estão no módulo parcial quando directory.py é carregado.

# core/loaders/__init__.py line 1: from parakeet_index.core.loaders.base import BaseFileLoader, BaseLoader # ✓ line 2: from parakeet_index.core.loaders.directory import DirectoryLoader # dispara directory.py # core/loaders/directory.py line 8: from parakeet_index.core.loaders import BaseFileLoader, BaseLoader ↑ encontra o módulo parcial, que JÁ TEM BaseLoader (linha 1 do __init__ já rodou) # ✓ # RISCO: se alguém inverter a ordem das linhas no __init__ ou adicionar # um import de base.py antes da linha 1 → NameError em runtime.

Recomendação: trocar o import em directory.py linha 8 para apontar diretamente ao módulo concreto:

- from parakeet_index.core.loaders import BaseFileLoader, BaseLoader + from parakeet_index.core.loaders.base import BaseFileLoader, BaseLoader
